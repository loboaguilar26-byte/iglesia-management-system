description: Coordina el ciclo completo de ChetoOMG para una tarea de desarrollo autorizada.
argument-hint: "<objetivo>"
allowed-tools: Bash, Read, Glob, Grep, Edit, Write
---

Ejecuta `/cheto-orchestrate` para el objetivo indicado siguiendo `OBSERVAR -> ANALIZAR -> PLANIFICAR -> DELEGAR -> IMPLEMENTAR -> VALIDAR -> REVISAR -> DOCUMENTAR -> INFORMAR`. Usa agentes solo cuando aporten valor y registra cuáles se ejecutaron. Mantén auditorías en solo lectura, no edites simultáneamente los mismos archivos, conserva cambios preexistentes y solicita autorización para operaciones sensibles. Termina con el informe estructurado de `CLAUDE.md`.
