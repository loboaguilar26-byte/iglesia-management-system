---
description: Investiga y corrige un problema concreto con validación proporcional.
argument-hint: "<problema reproducible>"
allowed-tools: Bash, Read, Glob, Grep, Edit, Write
---

Ejecuta `/cheto-fix` para el problema descrito por el usuario. Reproduce cuando sea seguro, identifica causa raíz, inspecciona el diff preexistente, aplica el cambio mínimo, añade pruebas pertinentes y ejecuta validaciones reales. Si falta información esencial, pide solo esa información. No hagas commit, push, merge ni despliegue.
