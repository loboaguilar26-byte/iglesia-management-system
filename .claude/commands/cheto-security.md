Ejecuta `/cheto-security` como revisión de solo lectura. Examina autenticación, autorización server-side, roles, acceso cruzado entre iglesias, datos sensibles, sesiones, entradas, secretos y dependencias. No pruebes sistemas externos ni producción. Reporta solo vulnerabilidades sustentadas, con severidad, confianza, evidencia y remediación.
