# Agentes de ChetoOMG

| Agente | Modo | Responsabilidad |
| --- | --- | --- |
| `architect` | Solo lectura | Arquitectura, límites, acoplamiento y alternativas |
| `code-auditor` | Solo lectura | Lógica, mantenibilidad, duplicación y deuda |
| `security-specialist` | Solo lectura | Auth, roles, sesiones, secretos y aislamiento |
| `developer` | Escritura autorizada | Implementación y pruebas de cambios acotados |
| `ui-ux-specialist` | Solo lectura | Accesibilidad, responsive y estados de UI |
| `qa-engineer` | Validación | Pruebas reproducibles y regresiones |
| `devops-engineer` | Solo lectura | CI, scripts, entorno y reproducibilidad |
| `documentation-engineer` | Escritura documental | Documentación alineada con el código |

Cada agente debe entregar evidencias, alcance, limitaciones y resultados reales. La existencia de un archivo de agente no demuestra que haya sido ejecutado.
