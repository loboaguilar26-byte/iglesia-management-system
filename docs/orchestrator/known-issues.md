# Limitaciones conocidas

- Claude Code no expone aquí una entidad persistente llamada ChetoOMG; la identidad se implementa mediante `CLAUDE.md`, agentes y comandos del proyecto.
- La configuración no crea un servidor, chatbot externo ni automatización periódica.
- Los agentes no se consideran ejecutados por el hecho de estar definidos.
- La validación de una tarea concreta debe ejecutarse desde Claude Code con el estado y las dependencias disponibles en ese momento.
- No se añadió un registro de tareas estructurado porque la documentación versionada es suficiente para el alcance inicial y evita introducir una base de datos o servicio adicional.
