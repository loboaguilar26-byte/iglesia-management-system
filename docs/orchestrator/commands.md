# Comandos de ChetoOMG

| Comando | Cambia archivos por defecto | Uso |
| --- | --- | --- |
| `/cheto-status` | No | Estado Git, tareas y validaciones conocidas |
| `/cheto-audit` | No | Auditoría técnica priorizada |
| `/cheto-security` | No | Revisión de seguridad |
| `/cheto-fix` | Sí, con solicitud | Corrección de un problema concreto |
| `/cheto-improve` | Sí, con alcance | Mejora justificada |
| `/cheto-test` | No | Validaciones disponibles |
| `/cheto-review` | No | Revisión del diff |
| `/cheto-report` | No | Informe técnico verificable |
| `/cheto-plan` | No | Plan de implementación |
| `/cheto-orchestrate` | Sí, con autorización | Ciclo completo de coordinación |

Los comandos son archivos Markdown nativos de `.claude/commands/`. Sus descripciones y parámetros son metadatos de Claude Code; la ejecución sigue las restricciones de `CLAUDE.md`.
